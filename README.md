# AI Backend Learning Roadmap

This repository is your hands-on path from AI fundamentals to production-ready AI services. It is designed for an experienced Java/Spring Boot engineer learning AI from the ground up.

Start with [docs/learning-path.md](docs/learning-path.md), then use [docs/progress.md](docs/progress.md) as your personal checklist.

## Repository layout

- `01-python-data/` — Python, notebooks, NumPy, pandas, and data visualization.
- `02-classical-ml/` — supervised learning and model evaluation with scikit-learn.
- `03-math-intuition/` — the essential math behind machine learning.
- `04-deep-learning/` — neural networks and PyTorch.
- `05-llm-engineering/` — prompting, embeddings, RAG, evaluation, and tool use.
- `06-production-ai/` — APIs, deployment, observability, and Java/Spring Boot integration.
- `projects/` — portfolio projects that combine the skills from multiple modules.
- `docs/` — roadmap, progress tracking, and learning notes.

Each module will contain its own `README.md`, exercises, and implementation notes as you progress.
