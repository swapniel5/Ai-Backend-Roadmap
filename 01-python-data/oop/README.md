# Object-Oriented Programming in Python

Each file demonstrates one core object-oriented programming concept:

1. `classes_and_objects.py` — defining a class and creating objects.
2. `encapsulation.py` — protecting data and controlling access through methods.
3. `inheritance.py` — reusing and extending behavior from a parent class.
4. `polymorphism.py` — using the same method call with different object types.
5. `abstraction.py` — defining a required interface while hiding implementation details.

Run any example from the repository root:

```bash
/opt/homebrew/bin/python3 01-python-data/oop/classes_and_objects.py
```
